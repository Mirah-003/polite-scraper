# Polite Scraper — Books to Scrape

A production-grade, polite web scraping pipeline built in Python. This system crawls catalogue pages from the Books to Scrape practice sandbox, normalizes raw text, validates records against a Pydantic schema, handles broken pages gracefully without crashing, exports clean data to JSON/CSV, and generates an interactive HTML metrics dashboard.

---

## 🎯 Target Classification

- **Target Site**: [Books to Scrape](https://books.toscrape.com/)
- **Site Type**: Sandbox (A practice website built specifically for web scraping practice).
- **Scope**: First 3 catalogue pages only (60 book items total).
- **Data Fields Collected**: Title, Product URL, Price Text, Price GBP (normalized), Availability, Star Rating, Description, Source Page (provenance), and Fetched At (timestamp).
- **Robots.txt Status**: `no robots file found` (HTTP 404 on `https://books.toscrape.com/robots.txt`).

> **Mandatory Compliance Statement**:
> I will not reuse this code on another site without checking its rules and terms first.

## 🛠️ Lane & Installation Guide

- **Language**: Python 3.10+
- **Core Libraries**: `requests` (HTTP Client), `beautifulsoup4` (HTML Parser), `pydantic` (Schema Validation).

### Quickstart (Single Command)

Clone the repository, activate your virtual environment, install dependencies, and run the pipeline:

```bash
# 1. Clone repository
git clone https://github.com/Mirah-003/polite-scraper.git
cd polite-scraper

# 2. Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the scraper pipeline
python src/main.py
```

## 📐 Record Schema (`BookRecord`)

Every scraped record is validated against a Pydantic schema before storage:

```python
class BookRecord(BaseModel):
    title: str                  # Required: Book title
    product_url: str            # Required: Absolute canonical URL
    price_text: str             # Required: Raw price string (e.g. "£51.77")
    price_gbp: float            # Required: Clean normalized price number (51.77)
    availability_text: str     # Required: Raw stock status
    rating_text: str            # Required: Star rating word ("One" to "Five")
    description: Optional[str]  # Optional: Book summary (None if missing)
    source_page: str            # Required: Catalogue URL provenance receipt
    fetched_at: str             # Required: UTC ISO 8601 timestamp receipt
```

## 🤝 Politeness Rules Implemented

1. **Honest User-Agent Identification**: Every request sends a custom header identifying the bot: `FlyRankInternship-A9/1.0 (+https://github.com/Mirah-003/polite-scraper)`.
2. **Request Timeout Safety**: All HTTP calls set a 10-second timeout (`timeout=10`) to prevent deadlocks.
3. **Throttling & Delays**: Real network requests wait 0.5 seconds (`time.sleep(0.5)`) between calls so as never to hammer the target server.
4. **Local Disk Caching (`cache/`)**: Downloaded HTML pages are stored locally. Development runs read from disk cache (`CACHE HIT`) with zero network overhead.
5. **Selective Retry Policy**: Retries transient `5xx` server errors once after a 1-second delay; **never** retries `404 Not Found` or `403 Forbidden` responses.

## ⚖️ Ethics Note

Web scraping should always be conducted responsibly:
1. Always check for an official public API before scraping raw HTML.
2. Never bypass logins, paywalls, CAPTCHAs, or authentication blocks.
3. Respect server resources by throttling request rates and caching responses locally.
4. Collect only the minimum data required for your project.

---

## ⚠️ Honest Technical Limitation

This scraper is designed for static server-rendered HTML pages. It cannot execute dynamic client-side JavaScript (e.g. React/Vue single-page apps) or solve interactive CAPTCHA challenges without integrating a headless browser engine like Playwright.
